Anda menyambung pembinaan versi 2 app web dalam repositori ini. Baca **docs/SPEC-v2.md** (bahagian 1, 4, 8, 9), kemudian baca js/game/asas.js dan SEMUA game sedia ada dalam js/game/ untuk mengikut corak, gaya dan pembantu `GameAsas` yang sama. Baca juga js/data.js untuk medan data K9–K12.

TUGASAN 5 — game K9 hingga K12 (ikut jadual SPEC bahagian 8):
- **js/game/k09-kunci.js** — Pilih Kunci: pintu (`s_pintu.png`) dengan perkataan berlubang (cth. `__emah`, gambar jika ada) daripada `isi` dan `senarai` K9; tiga kunci (`s_kunci.png`) berlabel `opsyen` (dikocok). Kunci betul → kunci masuk lubang, pintu terbuka (animasi), perkataan penuh dibaca.
- **js/game/k10-mesin.js** — Mesin Imbuhan: kata dasar (`imbuhan[i][0]`) jatuh ke corong mesin (`s_mesin.png`); tiga butang imbuhan pada mesin (imbuhan betul `imbuhan[i][1]` + 2 imbuhan lain daripada set me-, ber-, ter-, -an, -i, -kan). Ketik betul → mesin bergoyang, hasil (`imbuhan[i][2]`) keluar di tali sawat dan dibaca.
- **js/game/k11-keretaayat.js** — Kereta Api Ayat: gambar ayat K11 (`ayat[i].img`), kepala kereta (`s_kepala_kereta.png`) + slot gerabak = bilangan perkataan; gerabak (`s_gerabak.png`) berlabel perkataan dikocok. Ketik ikut urutan → gerabak bersambung. Lengkap → ayat dibaca (`Suara.main(s)`), kereta bergerak keluar. Perkataan boleh berulang dalam ayat — `tandaBetul` mesti pada SATU gerabak yang belum digunakan. Susun gerabak dalam beberapa baris jika tidak muat pada 360px.
- **js/game/k12-detektif.js** — Detektif Cerita: petikan K12 (`petikan[i]`) dengan gambar; setiap baris `teks` ialah butang; soalan dipapar besar. Murid ketik baris yang mengandungi jawapan; kanta (`s_kanta.png`) bergerak ke baris yang diketik. Betul → baris diserlah hijau + jawapan (`opsyen[0]`) dipapar dan dibaca. Tentukan baris jawapan: baris pertama yang mengandungi perkataan kunci daripada `opsyen[0]` (abaikan huruf besar/kecil dan tanda baca; abaikan perkataan umum "ya", "tidak", "ini", "di", "semasa", "bas" jika ada perkataan lain yang lebih khusus — cth. "Ya, bas ini baru." → baris dengan "baru"; "Kuning" → baris dengan "kuning"; "Doktor Ramli" → baris dengan "Ramli"; "Di hospital" → "hospital"; "Rawat pesakit" → "pesakit"; "Kak Ros" → "Ros"; "Berwarna-warni" → "berwarna-warni"; "Semasa hujan" → "hujan"; "Bapa Abu" → baris PERTAMA dengan "Abu"). Tulis fungsi ini dengan jelas dan uji untuk SEMUA soalan dalam data (log amaran jika tiada baris ditemui).

Setiap game: `GAME['Kn'] = { nama, latar, arahan, mula, henti }`, guna `GameAsas` seperti game lain; `GameAsas.soalanBaru(jawapan)` dan `GameAsas.tandaBetul(el)` WAJIB; soalan berulang rawak hingga masa tamat; bersihkan pemasa dalam `henti()`; mesra 360px.
